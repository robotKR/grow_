# grow

![test](https://github.com/robotKR/grow/actions/workflows/test.yml/badge.svg)

習慣を続けた日付の一覧から、木の成長を計算するコマンドです。
連続して続けるほど成長の倍率が上がります。
1日でも途切れると倍率は1.0に戻りますが、それまでの成長量は減りません。

## インストール

```
$ git clone https://github.com/robotKR/grow.git
$ cd grow
$ chmod +x grow
```

## 使い方

標準入力から日付（`YYYY-MM-DD`形式）を1行に1つずつ、古い順に読み込みます。

```
$ cat log.txt
2026-11-01
2026-11-02
2026-11-03
2026-11-05
2026-11-06
$ ./grow < log.txt
2026-11-01 1 1.0 10 10 seed
2026-11-02 2 1.1 11 21 seed
2026-11-03 3 1.2 12 33 sprout
2026-11-05 1 1.0 10 43 sprout
2026-11-06 2 1.1 11 54 sprout
```

各行は、入力した日付ごとに次の値を空白区切りで出力します。

| 列 | 内容 |
| --- | --- |
| 1 | 日付 |
| 2 | 連続日数 |
| 3 | 成長倍率 |
| 4 | その日の成長量 |
| 5 | 成長量の合計 |
| 6 | 成長段階 |

- 空行は無視します。
- 正しくない日付がある場合や、日付が1つもない場合は、標準エラー出力にメッセージを出し、終了ステータス1で終了します。

### 使用例

最後の行だけを見れば、現在の状態がわかります。

```
$ ./grow < log.txt | tail -n 1
2026-11-06 2 1.1 11 54 sprout
```

Gitのリポジトリで、コミットした日を習慣として木を育てられます。
`git log`は新しい順に同じ日付を何度も出力するので、`sort -u`で古い順に並べて重複を消してから渡します。

```
$ git log --format=%as | sort -u | ./grow
```

## 成長のしくみ

- 1日あたりの成長量は、10に倍率を掛けた値です。
- 倍率は連続1日目が1.0で、1日続くごとに0.1ずつ上がります。上限は3.0です。
- 前日に記録がない日は、連続日数が1に、倍率が1.0に戻ります。
- 成長段階は、成長量の合計によって次のように変わります。

| 合計 | 段階 |
| --- | --- |
| 0〜 | seed |
| 30〜 | sprout |
| 100〜 | leaf |
